# My Portfolio

A clean, responsive portfolio website

---

## 🎨 Design Philosophy
This portfolio was built with a **"Less is More"** approach:
* **Animated Navigation:** Features a smooth, custom-animated navbar with Font Awesome integration.
* **Visual Arts Focus:** Uses a balanced color palette and thoughtful typography to maintain a clean theme

---

## 🛠️ Technical Stack
* **HTML5:** Semantic structure for better SEO and accessibility.
* **CSS3:** Custom properties (variables), Flexbox, and Grid for a modern layout.
* **JavaScript:** Vanilla JS for the dynamic year footer and responsive mobile menu toggles.
* **Icons:** Font Awesome (Light/Pro style) for a premium look.
